# 演示图片来源与说明

示例采用 NASA 宇航员 Eileen Collins 的公开照片，通过 scikit-image v0.19.3 的 `astronaut.png` 样例取得。NASA 作品通常为公有领域，人物肖像、NASA 标识的使用仍受相应规则约束。

- 来源：https://github.com/scikit-image/scikit-image/blob/v0.19.3/skimage/data/astronaut.png
- NASA 图片使用规则：https://www.nasa.gov/nasa-brand-center/images-and-media/
- 仓库样例：`examples/astronaut.png`

截图通过真实软件导入图片并完成 ViT + DeepFace 双模型推理取得，没有手工填写预测值。主模型约 23.1 岁、第二模型约 14.0 岁，主模型参考区间 19–27。该区间为人工参考范围，不是统计置信区间。样例不提供真实年龄标签，不能据此计算准确率。模型输出出现明显分歧，应保留人工复查。

重现：在完整运行包中启动年龄评估工具，选择含此样例的目录，主模型选择 ViT，开启第二模型对比，然后开始推断。硬件、依赖或版本变化可能使耗时及浮点末位有所差异。

截图和公开样例已加入 GitHub 仓库介绍，运行包的软件及模型未改动。
